- 配置响应式图片尺寸


## 📱 响应式设计

### 断点系统
```css
@media (max-width: 1200px) { /* 大屏平板 */ }
@media (max-width: 992px)  { /* 平板 */ }
@media (max-width: 768px)  { /* 小平板 */ }
@media (max-width: 576px)  { /* 手机 */ }
```

### 自适应优化
- **图片容器高度**: 400px → 350px → 300px → 250px → 200px
- **网格列数**: 4列 → 3列 → 2列 → 1列
- **字体大小**: 使用 `clamp()` 函数自适应
- **间距调整**: 根据屏幕尺寸动态调整
