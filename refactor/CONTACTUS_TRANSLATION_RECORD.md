## 🔧 技术实现

### 文件结构
```
public/locales/
├── en/common.json          # 英语翻译
├── zh/common.json          # 中文翻译  
├── spanish/common.json     # 西班牙语翻译
└── arabic/common.json      # 阿拉伯语翻译
```

### 翻译键命名规范
```
contact.{模块}_{功能}
├── contact.hero_description     # Hero区域描述
├── contact.form_description     # 表单说明
├── contact.error_{field}        # 验证错误提示
├── contact.{field}_placeholder  # 输入占位符
└── contact.{action}             # 操作按钮
```

### 使用方式
```typescript
// React组件中使用
const { t } = useTranslation('common');

// 获取翻译文本
const heroDesc = t('contact.hero_description');
const nameLabel = t('contact.name');
const errorMsg = t('contact.error_name_required');
```
